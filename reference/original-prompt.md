Create a playable web-based farm game called “La Finca” in the style of Township.
Gameplay:
• Top-down / isometric view like the Township farm screenshot.
• Player controls a character with keyboard or touch.
• Start with chickens: walk up, collect eggs, and load them onto a truck to sell.
• Earn money → buy more land/space.
• Buy seeds → plant crops → wait for them to grow → collect → sell to trucks.
• Keep selling eggs while the farm grows little by little.
• Later, produce products inside the farm (example: grow tomatoes → make ketchup) and load them onto trucks.
• Hire workers that help manage and work the farm (they can plant, collect, or process).
• Simple money system and basic upgrades.
Cuban theme:
• Cuban flags on the farm.
• Cuban royal palm trees.
• The farm looks a bit rundown / worn (like many places in Cuba), not shiny.
• Rural Cuban atmosphere and simple Cuban-style buildings/fences.
Technical requirements:
• Single HTML file or simple web project (HTML + CSS + JavaScript).
• Use canvas or a lightweight library (Phaser or plain canvas) so it runs in the browser.
• Make character movement and collecting feel responsive.
• Start with a working prototype: character, chickens + egg collection, one truck, money, and the ability to buy a small piece of land and plant seeds.
• Then expand with processing (tomato → ketchup) and workers.
Build the first playable version focused on chickens, eggs, the truck, and basic planting. Include Cuban flags and palm trees, and keep the farm looking a bit rundown.
